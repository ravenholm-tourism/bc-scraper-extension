# Bandcamp Album URL Scraper
This is a browser extension for Chrome that lets you paste a list of band names and album titles and search Bandcamp for the url of the album if it exists. It is meant to be used in conjunction with [ma-scraper](https://github.com/ravenholm-tourism/ma-scraper) to compile [This Toilet Tuesday](https://toiletovhell.com/category/this-toilet-tuesday/, a list of all new metal album releases each week.

To install:
- Download or clone this repo
- Open chrome://extensions
- Turn on Developer mode at the top right of the the extensions page
- Click "Load unpacked" and select the bc-volume-extension folder
